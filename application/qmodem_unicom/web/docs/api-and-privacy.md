# 隐私与共享登录说明

本说明适用于安装在路由器上的 QModem 联通流量查询功能。

## 登录与共享范围

先登录 LuCI，再登录本人或已获授权的联通账号。联通要求的图形验证或其他安全验证仍需手动完成。服务只查询账号资料和套餐余量，不办理套餐变更或订购业务。

LuCI 登录弹框在用户点击发送验证码后临时读取所选 SIM 的运营商短信，仅展示符合本次发送时间和新短信基线的完整收到短信，便于用户复制粘贴。短信内容不提交给查询后端，不写入浏览器存储；关闭弹框或登录成功后清空显示并停止监听。原有短信仍由短信服务按其既有规则保存，本功能不删除、不标记已读。短信验证码仅在用户点击登录时随登录请求提交。

一次联通登录完成后，路由器保存当前模组及 SIM 对应的联通会话，其他已登录 LuCI 且具有 QModem 权限的浏览器可以直接查询。换卡后不会自动复用原卡的会话。

在设置中选择“退出联通共享登录”会清除路由器保存的该卡会话，影响所有浏览器；它不退出 LuCI，也不取消任何联通业务。联通会话过期时需要重新登录及完成联通要求的验证。

## 数据保存

- 真实联通 Token 和 Cookie 保存在路由器的 `/etc/qmodem-unicom/sessions.json`，目录权限为 `700`，文件权限为 `600`，服务重启后可继续使用。保存的是登录后的会话，不保存登录密码或短信验证码。
- 会话以模组标识和 SIM 身份的摘要区分。文件还保存脱敏账号及更新时间。路由器管理员能够管理这份文件，路由器备份也可能包含该文件，应按账号凭证保管。
- 浏览器仅保存非敏感的共享会话引用、显示偏好和登录设备标识；后端不会向浏览器返回真实联通 Token 或 Cookie。旧版浏览器会话若仍有效，可在打开登录或详情页时验证并迁移到路由器，随后替换浏览器中的旧记录。
- 登录密码和短信验证码仅用于当前登录；官方验证上下文短期保存在内存中。正常日志不记录密码、验证码、Token、Cookie 或完整上游报文。

## 请求路径

浏览器通过同源的 `/cgi-bin/luci/admin/modem/unicom_api/` 请求路由器。入口检查 LuCI 登录状态、QModem 权限、请求来源、接口白名单与正文大小，并读取实际 SIM 身份建立会话关联。查询后端仅监听路由器回环地址。

后端直接访问联通的 `loginxhm.10010.com` 和 `m.client.10010.com`。需要官方安全验证时，浏览器加载联通提供的验证页面；不会跳过验证或把人脸验证替换成较弱方式。

`shared/` 接口提供登录状态、紧凑余量列表、旧会话迁移及退出共享登录。详情查询仍提供套餐余量、签约速率及已订业务；只返回展示需要的字段，手机号脱敏，副卡号码、姓名、跳转链接及真实凭证不返回。

## 数据口径

LuCI 列表展示运营商返回的流量包剩余量和总量，按完全相同的资源记录去重，不会因共享资费编号而丢弃不同流量包。未知额度显示“—”，不限量包单独标记；汇总只累加有额度的流量包。路由器本地流量统计与运营商计费口径可能不同，账单以联通官方系统为准。

签约速率不是实时测速值。详情页中的 QCI 若由已订业务推断，会明确标注“推断”。
