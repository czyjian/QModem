# 上游整合说明（2026-10-30）

本次以 `FUjr/QModem` 的 `c50bc9cd` 为整合分支起点，将用户仓库
`6bc0eca8` 的定制合入。合并提交的第一父提交是上游，第二父提交保留
用户仓库历史，不重写已经发布的提交。

保留上游 MHI、语音、SIP、短信国家码控制和 SQLite v4 升级。
短信编码器、后台发送接口、显式回复关联采用上游实现，不再沿用定制的
`international` 布尔参数。前端发送已解析的完整号码，并传
`country_code: ""`，避免后台重复加国家码。

在上游流程上增加以下定制：

- 默认国家优先采用每模组 `sms_default_country`，未配置时读取当前 SIM IMSI。
- 收件地址控件默认自动识别国家；已保存的显式国家码优先。
  修改国家码字段（包括清空）会关闭本次自动识别，也可以手动切换。
  地址预览和实际发送共用同一解析结果。
- 自动识别将有效的国内号、裸国际号和完整国际号规范化；短号码和中国
  `10` 开头的服务号码保持独立。无法确认的号码保持原样，支持上游的
  按原号码发送行为，不按任意后缀猜测联系人。
- 会话先规范化有效号码，再使用上游显式关联及冲突保护逻辑。
  历史原始号码、内容、消息 ID 和已读状态保持不变。
- 保留既有 APN 特例、拨号日志、邻区频段标识、IPv6 源路由和界面定制。

上游 `docs/issue-281-sms-addressing.md` 描述的是原版策略；本定制版的
自动国家识别及相关差异以上述说明为准。旧 Lua 短信页维持上游显式国家码方案。

本次不改变模组 USB 模式，禁止将 `AT+GTUSBMODE` 设置为 `40`。
